# Calculator App
 
A fully functional calculator, built for the **CodSoft Web Development Internship — Level 1, Task 3**.
 
## Features
- Addition, subtraction, multiplication, division
- Chained calculations 
- Decimal and percentage support
- Clear (AC) and backspace (DEL)
- Divide-by-zero handled gracefully with an error state
- Full keyboard support
- Button layout built with CSS Grid
## Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
